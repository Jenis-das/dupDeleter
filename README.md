# 🧹 Image Copy Cleaner (dupDeleter)

A simple Python script to **automatically delete copied image files** from a folder based on filename keywords.

Most people delete duplicate photos manually.  
This script does it **fast, safely, and automatically** 🚀

---

## ✨ Features
- Deletes **only image files**
- Targets files whose names contain **`copy`** (case-insensitive)
- Shows a **preview before deleting**
- Asks for **confirmation**
- Uses **absolute path** for safety
- Beginner-friendly & fast

---

## 📁 Supported Image Formats
- `.jpg`
- `.jpeg`
- `.png`
- `.webp`
- `.bmp`
- `.gif`
